In spring 2027, four courses build directly on semester 1. **Programming Basics II** and **Object Oriented Programming** together make up 12 of the 30 ECTS credits in spring, so getting C and SQL solid first gives you the biggest head start.

:::note Ask your department
Check with the department secretary whether you will take the fall courses next autumn, or whether any previous credits can transfer. Either way, knowing this material puts you on the same footing as your classmates.
:::

## Spring courses and what they need

| Spring course | ECTS | First spring topics | What it assumes from semester 1 |
| --- | --- | --- | --- |
| **Programming Basics II (CMP154)** | 5 | Advanced flowcharts, `struct`s (arrays of structs, nested structs), pointers, string functions, file I/O (add/list/update/delete records), testing | All of CMP153, especially [Functions](#/lesson/c-11), [Arrays](#/lesson/c-12), [Pointers](#/lesson/c-13) and [Strings](#/lesson/c-15) |
| **Object Oriented Programming (CMP157)** | 7 | Java fundamentals, Eclipse IDE, classes & objects, access modifiers, sorting & searching, inheritance, polymorphism, UML | [Variables](#/lesson/c-05), [Operators](#/lesson/c-07), [Decisions](#/lesson/c-08), [Loops](#/lesson/c-09), [Arrays](#/lesson/c-12) — Java syntax looks very similar to C |
| **Database Management Systems II (CMP152)** | 7 | Re-covers ER & normalization quickly, then SQL functions, advanced queries, T-SQL transactions & concurrency, tuning, security, backup | All of CMP151: [ER diagrams](#/lesson/db-03), [Normalization](#/lesson/db-04), [SELECT](#/lesson/db-09), [JOINs](#/lesson/db-11) |
| **Mathematics II (MTH154)** | 4 | Functions, logarithms, trigonometry, matrices, limits, derivatives, integrals | [Exponents](#/lesson/math-06), [Radicals](#/lesson/math-07), [Factoring](#/lesson/math-08), [Equations](#/lesson/math-09), [Inequalities](#/lesson/math-11) |

Spring also includes **Turkish Language II**, **Atatürk Principles II** and **Advanced English Skills II**, which continue their semester 1 counterparts.

## Recommended priority order

1. **C programming and SQL** fully solid (do the mock exams and coding/SQL challenges).
2. **Bridge previews for C (`struct` and files) and Java** (lessons 2–5 in this module).
3. **Database functions & views preview** (lesson 6) and **Math II preview** (lessons 7–8).

## Key terms
- struct | a custom C type that groups related variables under one name | yapı (struct)
- class | a blueprint for objects in Java (data + methods together) | sınıf
- view | a saved SQL SELECT query that acts like a virtual table | görünüm (view)
- logarithm | the inverse operation of an exponent | logaritma
