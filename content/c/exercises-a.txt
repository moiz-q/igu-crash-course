=== c-05-08 | exam | run | Swap two variables using a temporary

=== c-08-06 | medium | run | Simple switch calculator
Read two integers `a` and `b` and an operator `op` (`+`, `-`, `*`, `/`) on one line (e.g. `10 3 +`). Use `switch (op)` to print the integer result (for `/`, print `Zero` if `b == 0`).
--- stdin
12 4 *
--- solution
#include <stdio.h>

int main() {
    int a, b;
    char op;
    scanf("%d %d %c", &a, &b, &op);
    switch (op) {
        case '+': printf("%d\n", a + b); break;
        case '-': printf("%d\n", a - b); break;
        case '*': printf("%d\n", a * b); break;
        case '/':
            if (b == 0) printf("Zero\n");
            else printf("%d\n", a / b);
            break;
        default: printf("Invalid\n");
    }
    return 0;
}
--- hint
Remember ` %c` in `scanf` and `break;` after each `case`.

=== c-08-07 | medium | run | Largest of three numbers

14 29 21
--- solution

int main() {
    int a, b, c;
    scanf("%d %d %d", &a, &b, &c);

=== c-08-08 | exam | run | Leap year check
Read a year `y`. Print `Leap` if it is divisible by 400, OR divisible by 4 and NOT divisible by 100; otherwise print `Normal`.
--- stdin
2024
--- solution

int main() {
    int y;
    scanf("%d", &y);
    if ((y % 400 == 0) || (y % 4 == 0 && y % 100 != 0)) {

    } else {
        printf("Normal\n");
    }
    return 0;
}
--- checklist
- Checks `y % 400 == 0`
- Checks `y % 4 == 0 && y % 100 != 0`
- Combines conditions with `||` and prints `Leap` / `Normal`
