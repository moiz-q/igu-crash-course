? [01] Which organization/project created HTTP, HTML, and URLs in 1989?
- ARPANET ~~ ARPANET (1969) built packet switching
* CERN (Tim Berners-Lee) ~~ invented the World Wide Web in 1989
- IEEE ~~ IEEE standardizes Ethernet and Wi-Fi
- Cisco ~~ Cisco builds networking hardware
! Tim Berners-Lee proposed the World Wide Web at CERN in 1989.

? [02] Which topology uses the **most** cable because every node has a direct link to every other node?
- Bus ~~ single shared backbone
- Star ~~ one link per host to switch
- Ring ~~ one link to each neighbor
* Full mesh ~~ $n(n-1)/2$ links
! Full mesh maximizes redundancy at the cost of the most cabling.

? [03] Which device breaks up **both** collision domains AND broadcast domains?
- Hub ~~ one collision domain, one broadcast domain
- Layer 2 Switch ~~ separates collision domains per port, but shares one broadcast domain
* Router ~~ each router interface is a separate collision and broadcast domain
- Repeater ~~ extends Layer 1 signals only
! Routers separate broadcast domains (and collision domains).

? [04] Which Ethernet cable category supports 1 Gbps up to 100 m and is the minimum standard for modern Gigabit LANs?

* Cat5e ~~ supports 1000 Mbps (1 Gbps) up to 100 m
- RG-59 ~~ coaxial cable
- RJ-11 ~~ telephone connector
! Cat5e (and Cat6) support Gigabit Ethernet up to 100 meters.

? [05] In Packet Tracer, which tab on a PC lets you open **Command Prompt** to run `ping` and `ipconfig`?

? [06] In Guided Lab 1, why did `Switch0` learn `PC0`'s MAC address automatically?
- You typed it into Switch0's IP Configuration ~~ Layer 2 switches don't need manual MAC entry
* Switch0 reads the **Source MAC** of incoming frames and records the port in its MAC table ~~ dynamic MAC learning
- ARP asked the router ~~ there was no router in Lab 1
- `ping` programmed the switch ~~ any Ethernet frame triggers source MAC learning
! Switches dynamically learn source MAC addresses and their incoming port numbers.

? [07] Which OSI layer is responsible for starting, maintaining, and ending a communication dialog (session)?

? [11] Which IPv4 class is reserved for **multicast** (`224–239`)?

? [11] What is the IPv6 **loopback** address?

- `fe80::1` ~~ typical link-local gateway
- `2001:db8::` ~~ documentation prefix
! `::1` is the IPv6 loopback address.

? [12] How many **usable hosts** are in a `/24` (`255.255.255.0`) subnet?
- 256 ~~ total addresses before subtracting network and broadcast
* 254 ~~ $2^8 - 2 = 254$
- 255 ~~ broadcast is also reserved
- 126 ~~ `/25`
! A `/24` has 8 host bits: $2^8 - 2 = 254$ usable hosts.

? [12] What is the **block size** in the 4th octet for a `/28` (`255.255.255.240`) mask?
- 8 ~~ `/29`
* 16 ~~ $256 - 240 = 16$
- 32 ~~ `/27`
- 64 ~~ `/26`
! $256 - 240 = 16$, so subnets step by 16 (`0, 16, 32, 48...`).

? [13] You need **100 usable hosts** in one subnet. What is the smallest CIDR prefix that fits?
- `/26` ~~ 62 usable hosts (too small)
* `/25` ~~ $2^7 - 2 = 126$ usable hosts
- `/24` ~~ 254 usable hosts (larger than needed)
- `/27` ~~ 30 usable hosts
! $2^7 - 2 = 126 \ge 100$, so `/25` (`255.255.255.128`) is the smallest fit.

? [13] In `192.168.10.32/27`, what is the **last usable host** address?

- `192.168.10.63` ~~ broadcast address of `.32/27`
* `192.168.10.62` ~~ one below the broadcast `.63`
- `192.168.10.33` ~~ first usable host
! Block size 32 → range `.32–.63`; usable hosts are `.33–.62`.

? [14] Which command checks if your own PC's TCP/IP stack is functioning without touching any external cable or router?

- `tracert 1.1.1.1` ~~ sends packets across external routers
- `nslookup google.com` ~~ queries an external DNS server
! Pinging `127.0.0.1` tests the local TCP/IP stack internally.

? [14] What does `nslookup gelisim.edu.tr` return?

- Every router hop to the website ~~ `tracert` shows hops
- All open TCP ports on your PC ~~ `netstat` shows open ports
! `nslookup` queries DNS to resolve a domain name to its IP address.

? [14] On Windows, which command shows your **Default Gateway**?

? [14] In `tracert`, what does a line showing `*  *  *  Request timed out.` at one hop usually mean?

? [15] Why does **2.4 GHz** Wi-Fi often experience more interference than **5 GHz**?

? [16] Why should you disable **Telnet** (port 23) on routers and switches?
