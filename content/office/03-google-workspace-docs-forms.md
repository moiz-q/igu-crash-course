**Google Workspace** (Drive, Docs, Sheets, Slides, Forms, Sites) runs right in your browser with automatic saving and real-time multi-user editing.

## Google Docs collaboration

- **Suggesting mode** (top-right pencil icon → **Suggesting**): edits appear as colored tracked suggestions instead of overwriting text—great for group reports!
- **Comments** (`Insert → Comment` or `Ctrl+Alt+M`): tag a teammate with `@email` to assign a task.
- **Version history** (`File → Version history → See version history`): restore an earlier version if someone accidentally deletes a section.
- **Download as Word/PDF**: `File → Download → Microsoft Word (.docx)` or `PDF Document (.pdf)`.

## Google Forms (surveys & quizzes)

In **Google Forms** (`forms.google.com`):
1. Add questions: **Multiple choice**, **Checkboxes**, **Short answer**, **Paragraph**, or **Linear scale**.
2. Toggle **Required** on essential fields (like Student ID).
3. Click **Settings → Make this a quiz** to auto-grade MCQs.
4. Click **Responses → Link to Sheets** to collect every submission automatically in a spreadsheet!

## Google Sites (quick portfolio or project page)

In **Google Sites** (`sites.google.com`):
- Add pages (`Pages` tab), drag content blocks (`Insert` tab), embed a Google Doc/Form/Slide directly, and click **Publish** to get a clean URL.

## Every Google Forms question type

| Type | Use it for | Example |
| --- | --- | --- |
| **Short answer** | one line of text | Student ID |
| **Paragraph** | long text | "Any comments?" |
| **Multiple choice** | choose **one** option (round buttons) | Year of study |
| **Checkboxes** | choose **one or more** options (square boxes) | Which apps do you use? |
| **Dropdown** | choose one from a list that opens (saves space) | City |
| **File upload** | respondent uploads a file (needs a Google sign-in; files go to your Drive) | Upload your CV |
| **Linear scale** | a number on a scale, e.g. 1–5 | "How satisfied are you?" |
| **Rating** | stars/hearts/thumbs | Rate the event |
| **Multiple choice grid** | one choice per row in a table | Rate each course: Poor / OK / Good |
| **Checkbox grid** | several choices per row | Which days can you attend each session? |
| **Date** / **Time** | a calendar date / a clock time | Date of birth / Preferred time |

Other useful settings: **Required** switch · **Settings → Make this a quiz** (answer keys and points) · **Responses** tab → **Link to Sheets** (all answers go into a Google Sheet) · **Send** button → link, email or embed code.

## Google Calendar and Meet

- **Create an event:** click a time slot or **+ Create** → add title, date and time.
- **Invite people:** type their emails under **Add guests**. They get an email and can answer **Yes / No / Maybe**. Guest permissions: *modify event, invite others, see guest list*.
- **Video meeting:** click **Add Google Meet video conferencing** — a Meet link is added to the event automatically.
- **Recurring events:** *Does not repeat* → *Weekly on Monday*… (e.g. a weekly class).
- **Reminders:** notification 10 minutes before, or an email.
- **Share a calendar:** Settings → *Share with specific people*.

## Google Drive sharing (Viewer, Commenter, Editor)

Click **Share** on any file or folder:

| Role | Can… |
| --- | --- |
| **Viewer** | only see the file |
| **Commenter** | see and add comments / suggestions, but not change the text |
| **Editor** | change everything, and (by default) share it with others |

**General access:** *Restricted* (only added people) or *Anyone with the link*. **File → Version history → See version history** (`Ctrl+Alt+Shift+H`) shows every earlier version and lets you **restore** one. Several people can type in the same Docs/Sheets/Slides file **at the same time** (real-time collaboration) — each person has a coloured cursor.

## Common mistakes

- Forgetting to toggle **Required** on key fields like Name or Student ID in Google Forms.
- Turning on **"Restrict to organization users"** in Form Settings when external users also need to fill it out.
- Editing directly in **Editing** mode when reviewing a teammate's draft instead of **Suggesting** mode.

## Key terms

- Suggesting mode | Google Docs mode that proposes edits for review without permanent overwrite | öneri modu
- Version history | timeline of saved snapshots allowing rollback to earlier drafts | sürüm geçmişi
- Google Forms | web tool for surveys and quizzes that exports responses to Google Sheets | Google Formlar

## Quick check

? In Google Docs, which mode lets you propose changes to a teammate's paragraph so they can accept or reject each edit?
- Viewing ~~ read-only
* Suggesting ~~ marks insertions/deletions for approval
- Printing ~~ print layout preview
- Offline ~~ allows editing without internet
! Suggesting mode works like Track Changes in Microsoft Word.

? Where do you go in Google Docs to recover a paragraph deleted two hours ago?
- `Edit → Undo` only ~~ Undo only steps back within the current session
* `File → Version history → See version history` ~~ stores timestamped snapshots across sessions
- `Tools → Word count` ~~ counts words/characters
- `View → Print layout` ~~ toggles page view
! Version history lets you inspect and restore previous saved states.

? How do you automatically save every Google Form submission into a table for analysis?
- Screenshot each response ~~ manual and error-prone
* Under the **Responses** tab, click **Link to Sheets** ~~ streams every new submission into a Google Sheet
- Export to `.pptx` ~~ PowerPoint is for slides
- Copy from `Tools → Script` ~~ unnecessary
! Linking a Form to Google Sheets creates a live spreadsheet of responses.
