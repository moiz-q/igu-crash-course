Academic and technical reports require structured **tables**, numbered **figures**, **citations**, and **reviewing tools**.

## Tables & captions

- **Insert Table**: `Insert → Tables → Table` (choose rows × columns). Use **Table Design** and **Layout** tabs (which appear when your cursor is inside the table) to merge cells, shade headers, and repeat header rows across pages (**Repeat Header Rows**).
- **Captions for figures/tables**: Right-click an image or table → **Insert Caption** (e.g., `Figure 1: Network topology`) or `References → Captions → Insert Caption`. Word automatically renumbers captions if you insert a new figure earlier!

## Citations & Bibliography

Under `References → Citations & Bibliography`:
1. Choose **Style** (e.g., `APA` or `IEEE`).
2. Click **Insert Citation → Add New Source** to enter author, title, and year.
3. At the end of your report, click **Bibliography → Insert Bibliography** to generate a formatted reference list.

## Reviewing & exporting

- **Track Changes**: `Review → Tracking → Track Changes` (`Ctrl+Shift+E`) highlights every insertion and deletion for group editing.
- **Export to PDF**: `File → Save As` (choose `PDF (*.pdf)`) or `File → Export → Create PDF/XPS`.

## Editing helpers: AutoCorrect, Paste Special, Find/Replace/Go To

- **AutoCorrect** fixes typing mistakes automatically (*teh → the*, `(c)` → ©). **File → Options → Proofing → AutoCorrect Options…** — add your own entries or turn rules off. Press `Ctrl+Z` straight after an unwanted correction to undo it.
- **Paste Special:** Home → Paste arrow → **Paste Special…** (`Ctrl+Alt+V`). Choose **Unformatted Text** to remove the source formatting, or paste as a picture / link. The small **Paste Options** button offers *Keep Source Formatting*, *Merge Formatting*, *Keep Text Only*.
- **Find** `Ctrl+F` (Navigation pane) · **Replace** `Ctrl+H` (Replace All changes every match) · **Go To** `Ctrl+G` or `F5` (jump to a page, section, line, bookmark, table…).
- **Templates:** File → **New** → search online templates (CV, letter, report) or save your own as **Word Template (*.dotx)**.

## Common mistakes

- Numbering figures manually (`Figure 1`, `Figure 2`…) and forgetting to renumber `Figure 2`–`Figure 10` after inserting a new image at the top. Use **Insert Caption**!
- Sending a `.docx` with **Track Changes** still unaccepted/visible when submitting a final assignment—always **Accept All Changes** and turn Track Changes off before final PDF export.
- Copying bibliography text with mixed fonts instead of using `References → Bibliography`.

## Key terms

- caption | an auto-numbered label (`Figure 1`, `Table 1`) attached to an image or table | resim yazısı / başlık
- Track Changes | Word reviewing mode that records every edit for acceptance or rejection | değişiklikleri izle
- bibliography | the formatted list of cited sources at the end of a document | kaynakça

## Quick check

? Where in Microsoft Word do you turn on **Track Changes** to review edits made by teammates?
- `Home → Styles` ~~ Styles format headings
- `Insert → Comments` ~~ inserts comments only
* `Review → Tracking → Track Changes` ~~ records insertions, deletions, and formatting changes
- `References → Captions` ~~ numbers figures and tables
! Track Changes lives under the **Review** tab.

? Why is `References → Insert Caption` better than typing `"Figure 1"` as normal text below an image?
- It makes the image higher resolution ~~ captions don't alter image pixels
* Word automatically renumbers all figures if you add or move one, and can build a List of Figures ~~ saves manual renumbering errors
- It converts the image to PDF ~~ unrelated
- It prevents copying ~~ unrelated
! Auto-captions keep numbering consistent and allow a List of Figures.

? Before submitting a final report exported from Word, what should you check if **Track Changes** was used?
- Delete the whole file ~~ no need
* Accept (or Reject) all changes and turn Track Changes off before exporting to PDF ~~ ensures red/strikethrough markups don't appear in the final PDF
- Hide page numbers ~~ unrelated
- Change margins to 0 ~~ breaks printing
! Always resolve tracked changes before final submission.
