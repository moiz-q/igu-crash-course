**Microsoft Word** is the standard tool for lab reports, assignments, and CVs. Clean formatting and keyboard shortcuts save hours every semester.

## Core Ribbon paths (Microsoft 365 / Word)

- **Font & size**: `Home → Font` group (e.g., Calibri/Arial/Times New Roman 11–12 pt).
- **Paragraph alignment & spacing**: `Home → Paragraph` group (Left, Center, Right, **Justify** `Ctrl+J`; Line and Paragraph Spacing → `1.15` or `1.5`).
- **Format Painter**: `Home → Clipboard → Format Painter` (copies formatting from one selection to another; double-click to paint multiple places!).
- **Find & Replace**: `Home → Editing → Replace` (`Ctrl+H`)—great for fixing a misspelled term across a 20-page report in one click.
- **Show/Hide formatting marks**: `Home → Paragraph → ¶` (`Ctrl+*`)—reveals hidden spaces, tabs, and Enter breaks.

## Essential shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copy / Cut / Paste |
| `Ctrl+Z` / `Ctrl+Y` | Undo / Redo |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | Bold / Italic / Underline |
| `Ctrl+F` / `Ctrl+H` | Find / Find & Replace |
| `Ctrl+S` / `Ctrl+P` | Save / Print |

## The Word window and file security

- **Ribbon:** the tabs at the top (File, Home, Insert, Design/Draw, Layout, References, Mailings, Review, View). Each tab has **groups** of buttons. `Ctrl+F1` hides/shows the ribbon.
- **Quick Access Toolbar (QAT):** the small toolbar with Save / Undo / Redo. Add any button: right-click it → **Add to Quick Access Toolbar**.
- **Backstage view:** everything you see after clicking **File** — New, Open, Save As, Print, Info, Export, Options.
- **File formats:** `.docx` (normal Word document) · `.doc` (old Word 97–2003) · `.dotx` (**template**) · `.docm` (document with macros) · `.pdf` (fixed layout, for sharing/printing) · `.rtf` / `.txt`.
- **AutoSave:** the switch at the top-left. It saves every few seconds, but only for files stored in **OneDrive / SharePoint**. AutoRecover (File → Options → Save) saves a backup copy every *n* minutes for local files.
- **Protect Document:** **File → Info → Protect Document** → *Always Open Read-Only*, **Encrypt with Password** (needs a password to open), **Restrict Editing** (only comments / only form filling), *Add a Digital Signature*, **Mark as Final**.
- **Inspect Document:** **File → Info → Check for Issues → Inspect Document** finds and removes hidden data (comments, tracked changes, author name, hidden text) before you share a file. *Check Accessibility* and *Check Compatibility* are in the same menu.

## Formatting tools named in the exam

- **Format Painter** (Home → Clipboard, the paintbrush): copies formatting. **Click** once to use once; **double-click** to paint many places; `Esc` to stop. Shortcut: `Ctrl+Shift+C` / `Ctrl+Shift+V`.
- **Borders and Shading:** Home → Paragraph → Borders arrow → **Borders and Shading…** (paragraph borders, **Page Border** tab, shading colour). Page borders are also under **Design → Page Borders**.
- **Columns:** Layout → **Columns** → Two / Three / More Columns… (newsletter style). Insert a column break: Layout → Breaks → **Column** (`Ctrl+Shift+Enter`).
- **Bullets and Numbering:** Home → Paragraph. `Tab` makes a lower level; `Shift+Tab` a higher level.
- **Tabs:** click the ruler to set a tab stop; the tab selector (left of the ruler) chooses Left / Center / Right / Decimal tab.
- **Margins, Orientation, Size:** Layout → Page Setup.

## Common mistakes

- Pressing `Space` ten times to center a title instead of using **Center align** (`Ctrl+E`).
- Pressing `Enter` ten times to start a new page—later edits push everything down! Use **Page Break** (`Ctrl+Enter`) instead.
- Pressing `Ctrl+V` when pasting from a website and bringing ugly background colors—use **Paste Special → Keep Text Only** (`Ctrl+Shift+V`).

## Quick check

? Which keyboard shortcut opens **Find & Replace** in Microsoft Word?
- `Ctrl+F` ~~ opens Find only
* `Ctrl+H` ~~ opens Find and Replace
- `Ctrl+R` ~~ right-aligns paragraph in Word
- `Ctrl+B` ~~ toggles Bold
! `Ctrl+H` opens the Replace tab directly.

? What happens if you **double-click** the **Format Painter** button (`Home → Clipboard`)?
- It deletes all formatting ~~ that is Clear All Formatting
* It stays active so you can apply the copied formatting to multiple selections until you press `Esc` ~~ single-click applies once; double-click locks it on
- It saves the document ~~ `Ctrl+S` saves
- It opens Font settings ~~ `Ctrl+D` opens Font dialog
! Double-clicking Format Painter lets you format several items in a row.

? Why should you avoid pressing `Space` repeatedly to align text in Word?
- Word bans multiple spaces ~~ Word allows them, they just break easily
* Different fonts, margins, or PDF exports will shift the alignment ~~ use Alignment buttons or Tab stops instead
- It deletes the paragraph ~~ it does not delete text
- It doubles the file size ~~ negligible size impact
! Always use paragraph alignment or tabs, never repeated spaces.
