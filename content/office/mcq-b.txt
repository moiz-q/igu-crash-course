# Office Applications MCQ Bank (Part B: Lessons 07–13)

? [07] What character **must** every Excel formula begin with?
- `#` ~~ `#` starts error codes like `#DIV/0!`
* `=` ~~ tells Excel to evaluate the cell as a formula
- `@` ~~ used in mentions, not standard formula start
- `$` ~~ `$` locks cell references inside a formula
! Every Excel formula starts with `=`.

? [07] Cell `C2` has `=A2*B2`. You copy `C2` down one row to `C3`. What formula is in `C3`?
- `=A2*B2` ~~ relative references shift when copied
* `=A3*B3` ~~ both relative row numbers increment by 1
- `=B2*C2` ~~ copying down changes rows, not columns
- `=$A$2*$B$2` ~~ no `$` locks were used
! Relative references adjust automatically when dragged or copied.

? [07] You want every row in `D2:D20` to multiply its price (`C2`) by a single VAT rate stored in `F1`. Which formula in `D2` is correct before dragging down?
- `=C2*F1` ~~ `F1` will shift to `F2, F3...`
* `=C2*$F$1` ~~ `$F$1` locks both column F and row 1
- `=$C$2*F1` ~~ locks `C2` instead of `F1`
- `=C2*&F1` ~~ `&` is invalid syntax here
! Use `$F$1` (shortcut `F4`) to lock the single rate cell.

? [07] Which shortcut key cycles through `$A$1`, `A$1`, `$A1`, and `A1` while editing a cell reference in Excel's formula bar?
- `F1` ~~ Help
- `F2` ~~ Edit active cell
* `F4` ~~ cycles absolute/mixed `$` reference modes
- `F5` ~~ Go To / Slide Show in PowerPoint
! Pressing `F4` toggles `$` locks on the selected reference.

? [07] What does `###` inside an Excel cell indicate?
- Invalid formula syntax ~~ shows `#NAME?` or error dialog
* The column is too narrow to display the formatted number or date ~~ double-click the column border to auto-fit
- Division by zero ~~ shows `#DIV/0!`
- Circular reference ~~ warns about self-referencing loop
! Widen the column when Excel displays `###`.

? [07] Why should you type `150` and apply **Currency** formatting instead of typing `"150 TL"` manually into an Excel cell?
- `"150 TL"` deletes the cell ~~ it stays as text
* Typing `"TL"` turns the cell into **plain text**, so `SUM` and math formulas ignore or fail on it ~~ number formatting displays `₺150` while keeping the value numeric `150`
- Excel bans currency symbols ~~ Excel has built-in Currency/Accounting formats
- It makes the font smaller ~~ unrelated
! Keep numbers purely numeric and apply Number/Currency formatting for display.

? [07] What does the mixed reference `$A2` lock when copied across columns and down rows?
- Both column A and row 2 ~~ that is `$A$2`
* Only **column A** stays locked; row 2 can change ~~ `$` only locks the part immediately after it
- Only **row 2** stays locked; column A can change ~~ that is `A$2`
- Neither ~~ that is `A2`
! `$` before `A` locks column `A`; without `$` before `2`, row `2` shifts when copied down.

? [07] Which is a valid Excel **range** representing a rectangle from column B row 2 to column D row 8?
- `B2-D8` ~~ hyphen is subtraction
* `B2:D8` ~~ colon `:` defines a contiguous range
- `B2;D8` ~~ semicolon separates function arguments in Turkish locale, not range endpoints
- `B2..D8` ~~ not Excel syntax
! Excel ranges use a colon: `StartCell:EndCell` (`B2:D8`).

? [08] Which Excel function returns the **arithmetic mean** of `B2:B10`?
- `=MEAN(B2:B10)` ~~ Excel uses `AVERAGE`, not `MEAN`
* `=AVERAGE(B2:B10)` ~~ computes the average (`ORTALAMA` in Turkish)
- `=SUM(B2:B10)` ~~ returns the total sum
- `=COUNT(B2:B10)` ~~ counts numeric cells
! Use `=AVERAGE(...)` (Turkish: `=ORTALAMA(...)`).

? [08] Cells `A1:A5` contain `10`, `"Yes"`, *(blank)*, `20`, and `"No"`. What does `=COUNT(A1:A5)` return?
* `2` ~~ `COUNT` counts **numeric** cells only (`10` and `20`)
- `3` ~~ `3` is neither numeric count (`2`) nor non-empty (`4`)
- `4` ~~ `4` is `=COUNTA(A1:A5)` (all non-empty cells)
- `5` ~~ blank cell is not counted
! `COUNT` counts numbers (`2`); `COUNTA` counts all non-empty cells (`4`).

? [08] What is the Turkish Excel equivalent of `=IF(B2>=50, "Pass", "Fail")`?
- `=TOPLA(...)` ~~ `TOPLA` = `SUM`
- `=ORTALAMA(...)` ~~ `ORTALAMA` = `AVERAGE`
* `=EĞER(B2>=50; "Pass"; "Fail")` ~~ `EĞER` = `IF` (with `;` separator in Turkish locale)
- `=MAK(...)` ~~ `MAK` = `MAX`
! Turkish Excel maps `SUM→TOPLA`, `AVERAGE→ORTALAMA`, `IF→EĞER`.

? [08] Which formula counts how many cells in `C2:C20` contain the word `"Istanbul"`?
- `=COUNT(C2:C20, "Istanbul")` ~~ `COUNT` does not accept criteria or count text
* `=COUNTIF(C2:C20, "Istanbul")` ~~ counts cells in range matching `"Istanbul"`
- `=IF(C2:C20="Istanbul", 1, 0)` ~~ returns an array, not a single count
- `=SUMIF(C2:C20, "Istanbul")` ~~ `SUMIF` sums numbers, not text
! `COUNTIF(range, criteria)` counts cells matching a condition.

? [08] Which error does Excel show if a formula divides by `0` or an empty cell?
- `#NAME?` ~~ unknown function or unquoted text
* `#DIV/0!` ~~ division by zero
- `#VALUE!` ~~ incompatible data type (e.g., text + number)
- `#REF!` ~~ deleted cell reference
! Dividing by zero produces `#DIV/0!`.

? [08] Why does `=IF(B2>=60, Pass, Fail)` produce a **`#NAME?`** error?
- `>=` is invalid ~~ `>=` is valid
* Text strings `Pass` and `Fail` must be inside double quotes (`"Pass"`, `"Fail"`) ~~ without quotes, Excel looks for named ranges called `Pass` and `Fail`
- `IF` needs 4 arguments ~~ `IF` takes 3 arguments
- `B2` should be `$B$2` ~~ relative references are valid
! Always wrap literal text in double quotes inside Excel formulas.

? [08] What does `=ROUND(3.14159, 2)` return?
- `3` ~~ `ROUND(..., 0)` returns `3`
- `3.1` ~~ `ROUND(..., 1)` returns `3.1`
* `3.14` ~~ rounds to 2 decimal places
- `3.15` ~~ third digit is `1`, so it rounds down to `3.14`
! `ROUND(number, 2)` rounds to 2 decimal places.

? [08] Which formula finds the **smallest** score in `D2:D30`?
- `=LOW(D2:D30)` ~~ not an Excel function
* `=MIN(D2:D30)` ~~ returns minimum numeric value
- `=MAX(D2:D30)` ~~ returns maximum
- `=SMALL(D2:D30)` ~~ `SMALL` requires a second `k` argument
! Use `=MIN(D2:D30)` for the smallest value and `=MAX(D2:D30)` for the largest.

? [09] Which shortcut toggles **AutoFilter** dropdown arrows on table headers in Excel?

- `Ctrl+H` ~~ Replace

? [09] Which Excel feature automatically colors cells red when a student's grade is below `60`?

* **Conditional Formatting** (`Home → Conditional Formatting`) ~~ formats cells dynamically based on rules
- Goal Seek ~~ solves for an input value

? [09] Which chart type is **best** for showing each browser's percentage share of a 100% total market?
- Line chart ~~ best for trends over time
* Pie chart ~~ shows parts of a single whole (100%)
- Scatter plot ~~ shows correlation between two variables
- Stock chart ~~ shows financial high/low/close
! Pie charts work best for a few slices summing to 100%.

? [09] Which chart type is **best** for comparing average scores across 6 different university departments?
* Column / Bar chart ~~ clearly compares discrete categories side by side
- Pie chart ~~ hard to compare 6 close numeric averages visually
- Area line chart ~~ implies continuous time trend
- Bubble chart ~~ unnecessarily complex for 1 variable
! Use Column or Bar charts to compare categories.

? [09] Which menu path keeps Row 1 visible while scrolling down through hundreds of rows?
- `Data → Sort` ~~ reorders rows
* `View → Freeze Panes → Freeze Top Row` ~~ pins Row 1 at the top of the window
- `Home → Merge & Center` ~~ merges cells
- `Page Layout → Print Titles` ~~ repeats headers on printed pages, not on screen
! `View → Freeze Panes → Freeze Top Row` keeps Row 1 visible while scrolling.

? [09] What is the danger of highlighting **only one column** in a 4-column table and clicking Sort?
- Excel converts numbers to text ~~ unrelated
* That column sorts independently of the other columns, scrambling which grade belongs to which student! ~~ click one cell inside the table or select all columns together
- It deletes the header row ~~ headers stay or sort if unflagged
- It turns off AutoSave ~~ unrelated
! Always sort the entire table together so row records stay intact.

? [10] Where in PowerPoint do you add a logo or footer once so it automatically appears on **every** slide?

- `Slide Show → Rehearse Timings` ~~ practices timing

? [10] What is the modern standard **Slide Size** aspect ratio for classroom projectors and laptops?
- `4:3` Standard ~~ old square-ish projectors, leaves black bars on modern screens
* `16:9` Widescreen (`Design → Slide Size`) ~~ matches modern HD/4K displays
- `1:1` Square ~~ social media posts, not presentations
- `9:16` Vertical ~~ phone stories, not projectors
! Use `16:9` Widescreen (`Design → Slide Size → Widescreen`).

? [10] Why should you always click **Close Master View** after editing `View → Slide Master`?

- To delete all animations ~~ unrelated

? [11] What does the **6×6 rule** mean in slide design?
- Use 6 slides and 6 fonts ~~ use at most 2 fonts
* Aim for at most ~6 bullet points per slide and ~6 words per bullet ~~ keeps slides readable and scannable
- Use 6 pt font size ~~ 6 pt is microscopic! Use ≥ 20 pt body text
- Add 6 transitions per slide ~~ use 1 subtle transition
! The 6×6 rule keeps bullets short so the audience listens to you instead of reading walls of text.

? [11] What is the minimum recommended **body text size** for classroom presentations?
- 10 pt ~~ unreadable from the back row
- 12 pt ~~ good for Word reports, far too small for projectors
* 20–24 pt (at least 18–20 pt) ~~ clearly readable across a lecture hall
- 72 pt ~~ only for huge title slides
! Keep slide body text at **20 pt or larger**.

? [11] Which color combination gives the **worst** contrast on a bright classroom projector?

? [12] What is the key difference between **Transitions** and **Animations** in PowerPoint?
- Transitions only work on text ~~ Transitions apply to whole slides
* **Transitions** control how one **slide** moves to the next; **Animations** control how individual **objects** on a slide appear or move ~~ separate Ribbon tabs
- Animations cannot be timed ~~ Animation Pane controls exact timing
- Transitions require video files ~~ built-in effects
! Transitions = between slides; Animations = objects on a slide.

? [13] You used a custom downloaded font in `.pptx` and will present on a different computer. What are the two safest precautions?
